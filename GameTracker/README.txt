Приложение для отслеживания прогресса в играх Steam.
-----------------------------------------------------------------------------------------------------
1. Установите зависимости:
	pip install -r requirements.txt
2. Запустите приложение:
	python main.py
3.1 Получение SteamID вашего профиля:
	Открыть "Об аккаунте" в Steam, там и будет заветный ID
3.2 Получение AppID игры:
	store.steampowered.com/app/730/CounterStrike_2/ <-- цифры после /app/ и будут AppID
-----------------------------------------------------------------------------------------------------
Основной функционал:
- Добавление игр по AppID
- Импорт списка игр из .txt файла
- Автоматическая загрузка обложек и статистики из Steam
- Отслеживание часов и достижений
- Ручное и автоматическое выставление статусов (Пройдено, Платина и т.д.)
-----------------------------------------------------------------------------------------------------
Зависимости:
- Python 3.13
- PyQt6
- SQLite3
- python-steam-api
- dotenv
